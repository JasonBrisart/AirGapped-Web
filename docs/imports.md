# AirGapped-Web Imports

AirGapped-Web imports are manual archive registrations.

The browser-based version does not crawl websites or write files automatically.

Instead, an import means:

1. Preserved website files were placed into the archives folder.
2. Metadata was added to data/archive-data.js.
3. The website became searchable and browsable through AirGapped-Web.
